## Getting started

Open the relevant folder under `projects/` and follow its README and setup document. Supply your own local or sandbox configuration. Runtime environment files, detected credentials, business data exports, dependency caches, and internal work artifacts are excluded. SQL schema/functions are retained with business data statements omitted.

## Validation and provenance

Python/TypeScript syntax was compared with captured source; generated JSON and supported sensitive-value patterns were checked. Applications, migrations, database tests, and external integrations were not run. These are new sanitized snapshots; original commit history is linked from each project rather than imported or reassigned.
